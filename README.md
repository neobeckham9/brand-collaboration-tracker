## Overview
An internal CRM-style workflow tool designed for advertising business teams to manage brand collaboration opportunities, campaign requirements, and follow-up processes.

用于广告业务团队管理品牌合作机会、客户需求及跟进流程的内部CRM系统。

---

## Features
- Client information management（客户信息管理）
- Product & target audience tracking（产品与目标人群）
- Campaign requirement recording（合作需求记录）
- Pipeline stage management（跟进阶段管理）
- Bilingual UI（中英文切换）
- Local data persistence (localStorage)

---

- Tailwind CSS
