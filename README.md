# Brand Collaboration Tracker

品牌合作跟进系统

## Overview
An internal CRM-style workflow tool designed for advertising business teams to manage brand collaboration opportunities, campaign requirements, and follow-up processes.

## Features
- Client information management
- Product and target audience tracking
- Campaign requirement recording
- Pipeline stage management
- Bilingual UI (Chinese / English)
- Local data persistence (localStorage)

## Tech Stack
- React
- Vite
- Tailwind CSS

## Usage
```bash
npm install
npm run dev
